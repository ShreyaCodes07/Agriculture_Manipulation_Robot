# Agriculture_Manipulation_Robot

An agriculture robot project designed to support fruit detection, autonomous navigation, and robotic-arm manipulation.

## Project Repository

[View Agriculture Manipulation Robot on GitHub](https://github.com/ShreyaCodes07/Agriculture_Manipulation_Robot)

## Features

* Fruit detection
* Autonomous navigation
* 4-DOF robotic arm simulation
* Pick-and-place operation
* Mission planning
